# Tune Guess

Crea una pagina web la cual sea muy parecida a blindtest.gg y Spotiguess, la cual puedas crear salas multijugador e insertar playlists de spotify (da igual el tamaño maximo y que no pida ni client id ni client secret al usuario) y que tenga dos modos de juego, el de escribir el nombre de la cancion y artista, y el de opcion multiple, donde te reproducen la cancion y te dan cuatro opciones de cual puede ser, para github pages, a la hora de cargar la playlist, cargue todas las canciones de esta? y que cada vez que empiece un juego, agarre canciones aleatorias, no las mismas, ademas de arreglar para que se escuchen las cacniones y se reproduzcan automaticamente hasta que acabe el tiempo
